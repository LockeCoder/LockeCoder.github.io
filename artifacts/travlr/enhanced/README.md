# Travlr Getaways — CS 499 Enhanced Artifact

The enhanced Travlr Getaways project includes two source-code applications:

- [travlr-admin](./travlr-admin/) — Angular administration interface.
- [travlr-express](./travlr-express/) — Express REST API, authentication, and MongoDB integration.

The [original course artifact](../Original/CS465-travlr/) and [software engineering enhancement narrative](../CS499_Milestone_Two_Narrative.docx) are available alongside this directory.

This repository contains project source code, not a hosted application. Full dependency installation, database configuration, and end-to-end testing must still be completed before production use.
