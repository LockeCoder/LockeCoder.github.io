# ABCU Advising Assistance

## CS 499 — Algorithms and Data Structures

This artifact originates from CS 300 at Southern New Hampshire University.

The application is a C++ course advising system that supports course catalog management, course lookup, prerequisite information, and alphabetical course listings.
