## Portfolio Overview

This repository contains my CS-499 Computer Science Capstone ePortfolio, showcasing my technical development throughout Southern New Hampshire University's Computer Science program.

The portfolio includes three enhanced academic projects representing software design and engineering, algorithms and data structures, and databases. Each project contains original source code, enhanced source code, and a written narrative explaining the improvements, technical decisions, and relevant course outcomes.

**ePortfolio Website:** https://lockecoder.github.io/

## Featured Projects

### 1. Travlr Getaways — Software Design and Engineering

Originally developed for CS-465, Travlr Getaways is a full-stack travel application incorporating Express, Angular, MongoDB, RESTful APIs, and authentication.

The capstone enhancement focuses on strengthening application security, authentication and authorization, error handling, and overall software maintainability. It demonstrates my understanding of multi-layer application architecture and the importance of protecting backend operations.

[View Project](./artifacts/travlr/)

### 2. ABCU Advising Assistance — Algorithms and Data Structures

Originally developed for CS-300, this C++ application manages academic course information, course listings, and prerequisites.

The capstone enhancement expands prerequisite analysis through graph-based algorithms, dependency traversal, cycle detection, and topological sorting. These improvements demonstrate how different data structures and algorithms can solve increasingly complex problems while preserving existing functionality.

[View Project](./artifacts/abcu/)

### 3. Grazioso Salvare — Databases

Originally developed for CS-340, Grazioso Salvare is a Python and MongoDB application designed to manage animal shelter information.

The capstone enhancement introduces improved database queries, server-side filtering, pagination, aggregation, input validation, and automated testing. These improvements emphasize data integrity, maintainability, and more efficient database operations.

[View Project](./artifacts/grazioso/)

## Testing and Verification

GitHub Actions workflows provide automated verification for the three enhanced projects, including applicable compilation, unit testing, functional testing, and database integration checks.

- **Travlr Getaways:** Angular build verification, unit testing, and Express API integration checks using a temporary MongoDB database.
- **ABCU Advising Assistance:** C++17 compilation and functional testing covering course lookup, sorting, prerequisite analysis, and error handling.
- **Grazioso Salvare:** Python syntax validation, automated tests, and MongoDB integration checks.

The verification workflows and their execution history are available under the repository's [GitHub Actions](https://github.com/LockeCoder/LockeCoder.github.io/actions) section.

Successful automated checks demonstrate that the tested functionality meets the conditions exercised by those workflows. They do not guarantee that the applications are free of defects or ready for production deployment.

The GitHub Pages website hosts the ePortfolio and its supporting documentation. The applications themselves are provided as source code rather than as publicly hosted production services.
